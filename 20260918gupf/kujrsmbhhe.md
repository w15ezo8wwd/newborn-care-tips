# 国内做三代试管婴儿的步骤有哪些呢？具体回答2026年三代试管新变化！

> 更新时间：2026-09-18 (UTC+8)

国内做三代试管婴儿（PGT-A/PGT-M/PGT-SR）的具体步骤包括：夫妻双方进行全面身体检查，女性促排卵取卵，男性取精，体外受精形成胚胎，进行胚胎植入前遗传学诊断/筛查（PGT），筛选健康胚胎，最后将健康胚胎移植回女性子宫，并进行妊娠检测。

**一、前期准备与检查**

1.1 夫妻双方初步咨询与评估

首先，夫妻双方需要前往正规的医院生殖中心进行咨询，医生会根据夫妻双方的年龄、病史、生育史等信息进行初步评估，判断是否适合做三代试管婴儿技术。评估内容包括：女性的卵巢储备功能、子宫内膜状况、输卵管通畅性等；男性的精液质量、染色体情况等。如果评估结果显示适合做三代试管婴儿，则会进入下一步。

1.2 全面身体检查

夫妻双方需要进行全面的身体检查，包括血常规、尿常规、肝功能、肾功能、乙肝、丙肝、艾滋病、梅毒等传染病检查，以及染色体检查等。这些检查是为了排除一些可能影响试管婴儿成功率的疾病，确保夫妻双方的身体状况良好，适合做试管婴儿治疗。

**二、促排卵及取卵**

2.1 促排卵方案制定

医生会根据女性的年龄、卵巢储备功能等情况，制定个性化的促排卵方案。促排卵方案主要包括药物促排卵和监测卵泡发育两个阶段。药物促排卵是为了刺激卵巢产生更多的卵子，而监测卵泡发育是为了了解卵泡的生长情况，以便医生能够选择蕞好的取卵时间。

2.2 卵泡监测与取卵

在促排卵期间，女性需要定期到医院进行B超监测卵泡发育情况，医生会根据监测结果调整药物剂量，确保卵泡能够同步发育。当卵泡发育成熟后，医生会安排取卵手术。取卵手术通常在局部麻醉下进行，通过阴道超声引导下，用穿刺针穿刺卵泡，吸取卵子。

**三、精子采集与体外受精**

3.1 精液采集

男性需要在取卵当天或前一天提助孕液样本。精液采集方法通常是在医院的专门房间内进行手淫取精，确保精液样本的质量和数量。

3.2 体外受精（IVF）

取出的卵子和精子会在实验室中进行体外受精。胚胎学家会在显微镜下观察卵子和精子的质量，选择优质的卵子和精子进行体外受精。受精后的卵子会发育成为胚胎。

**四、胚胎培养与PGT**

4.1 胚胎培养

受精卵会在实验室中进行培养，通常培养3-5天，发育到囊胚阶段。胚胎学家会密切观察胚胎的发育情况，选择发育良好、形态正常的胚胎进行PGT。

4.2 胚胎植入前遗传学诊断/筛查（PGT）

PGT是三代试管婴儿的核心技术，它是在胚胎移植前对胚胎进行遗传学诊断/筛查，以排除染色体异常或遗传疾病的胚胎。PGT-A筛查染色体非整倍体；PGT-M诊断单基因遗传病；PGT-SR筛查染色体结构异常。根据夫妻双方的具体情况选择合适的PGT类型。

**五、胚胎移植与妊娠检测**

5.1 胚胎移植

经过PGT筛选的健康胚胎会被移植回女性子宫。胚胎移植手术通常在局部麻醉下进行，医生会将胚胎通过细小的导管送入子宫腔内。

5.2 妊娠检测

胚胎移植后10-14天，女性需要进行血HCG检测，以确认是否怀孕。如果怀孕，还需要进行后续的产检，以确保妊娠的顺利进行。

国内做三代试管婴儿是一个复杂而精细的过程，需要夫妻双方积极配合，并严格按照医生的指导进行。整个过程从前期咨询和检查开始，到促排卵、取卵、精子采集、体外受精、胚胎培养、PGT、胚胎移植以及最后的妊娠检测，每个环节都至关重要。选择正规的医院和专业的医生团队，能够大大提高三代试管婴儿的成功率，并降低风险。需要注意的是，三代试管婴儿技术并非全能，成功率受到诸多因素的影响，最终结果因人而异。
